# Cyprus Relocation — «Запасной аэродром»

Исходники лендинга о релокации на Северный Кипр.

## Состав репозитория

- `site/` — актуальная публичная версия сайта. Главный файл: `site/index.html`.
- `deploy_yandex_object_storage.py` — скрипт обновления сайта в Yandex Object Storage.

## Публичный сайт

https://north-cyprus-relocation-20260727-k7m4.website.yandexcloud.net

Внутренние брифы, расшифровки, исходные материалы и архивы остаются в локальной папке проекта и намеренно не размещаются в репозитории.
