# Cyprus Relocation — «Запасной аэродром»

Это единственная рабочая папка проекта. Все дальнейшие изменения лендинга нужно делать здесь.

## Где что находится

- `site/` — актуальная публичная версия сайта. Главный файл: `site/index.html`.
- `versions/` — две предыдущие развёрнутые версии в ZIP-архивах.
- `docs/` — бриф, передача проекта, комментарии клиента, архитектура, SEO-план и дизайн-гайдлайн.
- `source-assets/` — исходники логотипов и лицензии/исходные файлы шрифтов.
- `deploy_yandex_object_storage.py` — безопасное обновление существующего сайта в Yandex Object Storage.

## Публичный сайт

https://north-cyprus-relocation-20260727-k7m4.website.yandexcloud.net

## Правило дальнейшей работы

Не создавать рядом новые копии проекта и файлы вида `index-before-*`, `index-designed-*` или `backup`. Перед значимым обновлением при необходимости сохранять одну проверенную публичную сборку в `versions/`, после чего продолжать работу только в `site/`.

Подробная инструкция по публикации: `docs/DEPLOYMENT.md`.
