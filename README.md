# Запасной аэродром — Северный Кипр

Актуальный сайт: https://zapasnoy-aerodrom.com/

## Где находится сайт

- `site/` — файлы, которые публикуются на сайте.
- `site/index.html` — главная страница.
- `site/blog/`, `site/guides/`, `site/residence-permit/` — остальные страницы.
- `site/assets/` — используемые изображения, стили, шрифты и скрипты.
- `telegram-bot/` — отдельный код Telegram-бота; он не входит в публикацию сайта.

## Как публикуются изменения

После обновления ветки `main` процесс [Deploy site to GitHub Pages](.github/workflows/deploy-pages.yml) загружает папку `site/` в GitHub Pages. Публикация использует домен `zapasnoy-aerodrom.com`. Статус последнего запуска виден на вкладке **Actions**.

Для правок создавайте отдельную ветку и pull request. Перед объединением проверьте нужные страницы на компьютере и телефоне. После объединения проверьте успешное выполнение процесса публикации и открытие сайта.

## Доступы за пределами GitHub

Домен и DNS управляются отдельно у регистратора. Заявки и аналитика также используют внешние сервисы: Google, Telegram и Яндекс Метрику. Доступ к репозиторию сам по себе не даёт доступ к их настройкам.

План передачи владения клиенту: [TRANSFER_TO_MANIFEST.md](TRANSFER_TO_MANIFEST.md). До выполнения этого плана владелец репозитория — `anisimovkat-hub`.
